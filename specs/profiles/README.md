# Reference implementation profiles

Status: draft area; no accepted profile yet.

The first profile must specify exact signed bytes and encodings, authenticated metadata, clock boundaries, trusted key resolution, canonical JSON, parser limits, unknown CDL term treatment, override authority, enforcement topology, session binding, wire protocol versions, and error reason codes.

Open errata are not resolved by the scaffold. No implementation may claim that a convenience decision here supersedes a published RFC. Profile approval and normative changes follow `../PROCESS.md`.
